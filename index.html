Home SOC Lab – Detection & Incident Response

Built a simulated Security Operations Center (SOC) environment to generate, detect, and investigate cyber attacks using Splunk and Sysmon. This project demonstrates hands-on experience with SIEM monitoring, threat detection, and incident response workflows.

Tools: Splunk, Sysmon, Kali Linux, Wireshark, VirtualBox

Key Features

  • Simulated real-world attacks (port scanning, brute force, PowerShell abuse)
  • Created custom detection queries and alerts in Splunk
  • Performed incident investigation with timeline analysis
  • Documented response actions and mitigation strategies

Lab Setup

  • Attacker: Kali Linux
  • Target: Windows 10 (Sysmon enabled)
  • SIEM: Splunk (Ubuntu)

Attack Simulation

  • Port Scan: Identified open ports using Nmap
  • Brute Force: Simulated repeated login attempts
  • PowerShell Abuse: Executed encoded commands

Detection

Failed Login Detection:

PowerShell Detection:

Investigation

  • Identified attacker IP and targeted account
  • Correlated failed and successful login events

Incident Response

  • Outlined containment and remediation steps
