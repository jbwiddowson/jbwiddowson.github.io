Enterprise Cybersecurity Home Lab - Overview

Designed and built a fully virtualized enterprise network to simulate a real-world business environment. This home lab serves as the foundation for all cybersecurity projects, including Active Directory, SIEM monitoring, vulnerability management, threat hunting, incident response, and penetration testing.

Tools: Proxmox VE, Windows Server 2022, Windows 11, Ubuntu Server, Kali Linux, pfSense, Splunk Enterprise, Security Onion, Wireshark, OpenVAS, Docker, Sysmon

Project Goals

  • Build an enterprise-style virtual infrastructure
  • Deploy a Windows Active Directory domain
  • Create secure virtual networking and firewall segmentation
  • Centralize log collection using Splunk
  • Generate realistic attack scenarios for detection and analysis
  • Develop a reusable environment for future cybersecurity labs

Infrastructure

  • Hypervisor: Proxmox VE
  • Domain Controller: Windows Server 2022
  • Client Systems: Windows 11 & Ubuntu
  • Firewall: pfSense
  • SIEM: Splunk Enterprise
  • Network Security: Security Onion
  • Attacker: Kali Linux
  • Vulnerability Scanner: OpenVAS

Build Process

  • Installed and configured Proxmox on a dedicated rack server
  • Created isolated virtual networks and VLANs
  • Deployed Windows Server and promoted it to a Domain Controller
  • Configured Active Directory, DNS, DHCP, and Group Policy
  • Added Windows and Linux client systems to the domain
  • Installed pfSense to control and monitor network traffic
  • Configured centralized logging with Splunk
  • Integrated Security Onion for IDS and network monitoring

Security Features

  • Active Directory user and group management
  • Group Policy security hardening
  • Password complexity and account lockout policies
  • Windows Firewall configuration
  • Sysmon endpoint logging
  • Network segmentation using pfSense
  • Centralized event logging with Splunk
